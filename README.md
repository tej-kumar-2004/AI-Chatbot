# Task 01 - AI Chatbot 🤖

## 📌 Project Description

This project is a simple AI Chatbot developed using Python.

The chatbot can interact with users through the terminal and provide suitable responses based on predefined questions and basic text matching.

This project introduces the basic concepts of Artificial Intelligence (AI) and Natural Language Processing (NLP).

## ✨ Features

- Responds to greetings such as Hello and Hi
- Answers basic questions about AI
- Provides information about Python
- Explains Natural Language Processing (NLP)
- Responds to "How are you?"
- Handles thank-you messages
- Provides a response for unknown questions
- Allows the user to exit using `bye`, `exit`, or `quit`

## 🛠️ Technologies Used

- Python 3
- Basic Text Matching
- Conditional Statements
- Functions
- User Input
- Natural Language Processing (NLP) Concepts
